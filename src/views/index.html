    API reference
    
                    Examples use this server's address.
                
    
            
    

            
    
                
    
                    
    Send a message
    
                    
    
                        POST
                        /api/messages
                        
                    
    

                    
    Headers
    
                    
    
                        
    Content-Typeapplication/json
    
                        
    X-API-KeyA Send key from the API keys page (or INGEST_API_KEYS in .env)
    
                        
    AuthorizationOr, for clients that can't set custom headers: Bearer <Send key>
    
                    
    

                    
    Body
    
                    
    
                        
    senderOptional, up to 64 characters
    
                        
    phoneRequired. 6–15 digits, optional leading +. Spaces, dashes, dots and brackets are removed.
    
                        
    messageRequired, up to 1600 characters
    
                    
    

                    
    
                        
    Example
    
                        
                    
    
                    
    

                    
    Responses
    
                    
    
                        
    201Stored. Returns { success, id, timestamp }
    
                        
    400Invalid input; details lists the problem per field
    
                        
    401Missing or unknown API key
    
                        
    429Rate limit exceeded
    
                    
    
                
    

                
    
                    
    Read messages from scripts and tests
    
                    
    Send Authorization: Bearer <key> with a Read key from the API keys page (lists and reads messages), or ADMIN_TOKEN (everything, including delete). Phone numbers are masked unless you add unmask=true.
    
                    
    
                        
    GET/api/messages/latest?phone=…
    Newest matching message, or 404. Includes code: the detected OTP, or null
    
                        
    GET/api/messages
    search, phone, startDate, endDate, page, pageSize (max 100)
    
                        
    DELETE/api/messages/:id
    
                        
    DELETE/api/messages with { "ids": [1, 2] }
    
                        
    GET/health
    Public; { "status": "ok" } when the database is reachable
