API Settings

Use the following API endpoint to send messages from a third-party app:

POST http://localhost:3006/api/messages

Headers:

Content-Type: application/json
X-API-Key: <one of the keys in INGEST_API_KEYS>

Request Body (JSON):

{
    "sender": "Your Name",
    "phone": "1234567890",
    "message": "Your message here"
}
